# LifeSim 2026 🌏

2026년 대한민국을 살아가는 한 사람이 되어 보는 **채팅 주도형** AI 인생 시뮬레이터.
하고 싶은 무엇이든 채팅으로 입력하면 게임 마스터(AI)가 결과를 서술하고, 인생의 모든 영역이 실시간으로 갱신됩니다.

## 특징

- **채팅으로 사는 인생**: "카페 창업 자금을 알아본다", "그 사람에게 고백한다", "주식에 100만원 넣는다" 등 자유롭게 입력하면 AI가 개연성 있게 전개합니다.
- **AI 게임 마스터**: OpenAI API가 인물의 나이·직업·자산·능력치·관계에 맞춰 2026년 현실 맥락(고물가, AI, 취업난, 부동산, SNS, 주식/코인 등)을 반영합니다.
- **도메인별 탭**: 자산 / 학업 / 일 / 사랑 / SNS / 인간관계 / 소지품 / 일지 — 모든 변화가 탭에 연결되어 한눈에 추적됩니다.
- **풍부한 상태**: 건강·행복·정신력·지능·외모·체력, 현금/예금/투자/빚/월수지, 학교·전공·학점·자격증, 직장·직급·연봉·만족도, 연애·결혼, 팔로워·영향력, 인간관계 친밀도까지.
- **폴백 모드**: API 키가 없어도 내장 채팅 엔진으로 바로 플레이할 수 있습니다.

## 실행

```bash
npm install
npm start
# → http://localhost:3000
```

AI 모드를 쓰려면 시작 화면의 **"🤖 AI 모드 설정"**에서 OpenAI API 키(`sk-...`)를 입력하세요.
(또는 `export OPENAI_API_KEY=sk-...` 후 실행해도 됩니다.) 키 없이 실행하면 내장 폴백 엔진으로 동작합니다.

## 구조

```
server.js        Express 서버 · 세션 · /api/chat 턴 진행 · AI 실패 시 폴백
src/game.js      상태 모델(자산/학업/일/사랑/SNS/관계 등) · 효과 적용 · 폴백 채팅
src/ai.js        OpenAI API 래퍼 · 채팅 게임 마스터 프롬프트/효과 스키마
public/          단일 페이지 프론트엔드 (채팅 + 도메인 탭)
```

## 설정 (환경변수)

키는 보통 UI에서 입력하지만, 환경변수로도 지정할 수 있습니다.

| 변수 | 기본값 | 설명 |
|------|--------|------|
| `OPENAI_API_KEY` | (없음) | UI에 키를 안 넣을 때 사용. 없으면 폴백 모드 |
| `LIFESIM_MODEL` | `gpt-4o` | 기본 모델 |
| `PORT` | `3000` | 서버 포트 |
