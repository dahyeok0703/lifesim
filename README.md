# LifeSim 2026 🌏

2026년 대한민국의 현실세계를 살아가는 한 사람이 되어 보는 AI 기반 인생 시뮬레이터.
매 턴 새로운 상황이 펼쳐지고, 선택지를 고르거나 **직접 행동을 입력**하면 AI가 개연성 있게 결과를 판정합니다.

## 특징

- **AI 게임 마스터**: OpenAI API가 인물의 나이·직업·자산·능력치·인간관계에 맞춰 2026년 현실 맥락(고물가, AI 보편화, 취업난, 부동산, SNS 등)을 반영한 사건을 동적으로 생성합니다.
- **자유 행동**: 정해진 선택지 외에 "카페 창업을 준비한다" 같은 자유 행동을 입력하면 AI가 결과를 판정합니다.
- **능력치 & 인생 시스템**: 건강·행복·지능·외모·체력, 자산(원), 직업, 학력, 인간관계, 노화, 사망까지.
- **폴백 모드**: API 키가 없어도 내장 절차적 이벤트 엔진으로 바로 플레이할 수 있습니다.

## 실행

```bash
npm install
npm start
# → http://localhost:3000
```

AI 모드를 쓰려면 시작 화면의 **"🤖 AI 모드 설정"**에서 OpenAI API 키(`sk-...`)를 입력하세요.
(또는 `export OPENAI_API_KEY=sk-...` 후 실행해도 됩니다.) 키 없이 실행하면 내장 폴백 엔진으로 동작합니다.

## 구조

```
server.js        Express 서버 · 세션/턴 진행 · AI 실패 시 폴백
src/game.js      게임 상태 모델 · 스탯/노화/사망 로직 · 폴백 이벤트
src/ai.js        OpenAI API 래퍼 · 이벤트 생성/결과 판정 프롬프트
public/          단일 페이지 프론트엔드 (HTML/CSS/JS)
```

## 설정 (환경변수)

키는 보통 UI에서 입력하지만, 환경변수로도 지정할 수 있습니다.

| 변수 | 기본값 | 설명 |
|------|--------|------|
| `OPENAI_API_KEY` | (없음) | UI에 키를 안 넣을 때 사용. 없으면 폴백 모드 |
| `LIFESIM_MODEL` | `gpt-4o` | 기본 모델 |
| `PORT` | `3000` | 서버 포트 |
