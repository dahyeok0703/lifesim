# LifeSim AI 🌆

2026년 대한민국을 살아가는 한 사람의 **초현실적 인생 시뮬레이션**.
하루는 6개의 시간대(아침/오전/오후/저녁/밤/심야)로 나뉘고, 매 시간대마다 행동을 고르거나 직접 입력하며 인생을 살아갑니다.

> 핵심 철학: **AI는 내레이터, 시스템은 판정관.**
> 돈·시간·체력·멘탈·확률·관계·상태 변화는 전부 결정론적 엔진이 계산합니다.
> AI는 이미 계산된 결과를 현실적으로 서술하고 NPC 대사를 만들 뿐, 수치를 만들거나 유저가 하지 않은 행동을 지어내지 않습니다.

## 무엇이 들어있나 (MVP)

- **캐릭터 생성**: 이름/나이/성별/지역/시나리오(12종)/장기 목표/성격/난이도(쉬움·보통·어려움·생존)
- **시간대 기반 루프**: 하루 6칸, 행동마다 시간·돈·체력·피로·스트레스·멘탈·능력·관계·평판 소모/변화
- **결정론적 판정**: 대성공/성공/부분 성공/실패/큰 실패 — 능력치·피로·스트레스·아이템·랜덤이 반영
- **상태창**: 기본정보·시간·돈(현금/통장/부채/신용/월수지)·몸·정신·능력·사회·관계 전부 추적
- **NPC 시스템**: 7명 자동 생성, 호감/신뢰/친밀/의심 + **과거를 기억**(약속·서운함 등), 먼저 연락하기
- **돈 시스템**: 월급·월세·관리비·통신·구독 고정비, 변동지출, 월말 자동 정산, 신용점수
- **건강·멘탈**: 수면/식사/밤샘/번아웃이 실제 판정과 사망(건강/멘탈 0)에 영향
- **장소 이동**: 집·헬스장·도서관·회사·병원·카페 등, 장소별 가능 행동/보너스/교통비
- **아이템/주거**: 노트북·정장·카메라 등 효과, 주거 유형별 수면/스트레스/월세
- **SNS·평판**: 팔로워/영향력, 바이럴·악플
- **랜덤 사건**: 감기·지각·폰 고장·충동소비·월세 인상·외주 제안·사기 DM 등 (상태에 따라 확률 변동)
- **장기 목표**: 진행률·필요 조건·현재 장애물 추적
- **요약/정산**: 하루 요약·주간 평가·월말 정산 모달
- **사건 로그**: 모든 행동/사건 기록, AI가 이후 서술에 참고
- **자유입력 + 버튼 선택지** 동시 지원
- **자동 저장**: localStorage (새로고침/재방문해도 이어하기)

## 실행

```bash
npm install
npm start
# → http://localhost:3000
```

AI 내레이션을 쓰려면 시작 화면(또는 설정 탭)에서 OpenAI API 키(`sk-...`)를 입력하세요.
**키가 없어도** 내장 내레이션으로 모든 기능이 동작합니다. (게임 수치는 어느 경우든 시스템이 계산)

## 구조

```
server.js                정적 서빙 + OpenAI 내레이션 프록시 (계산 안 함)
public/config.js         앱 이름/버전/저장키 등 — 여기만 바꾸면 리브랜딩
public/store.js          저장 계층(localStorage). 추후 Supabase로 교체 지점
public/ai.js             내레이터: 컨텍스트 구성·프록시 호출·폴백 내레이션·자유입력 의도추정
public/engine/
  util.js                공용 함수
  state.js               상태 모델·클램프·델타 적용 (수치의 단일 진실원)
  time.js                시간대/달력/요일/계절/수면
  content.js             데이터: 난이도·시나리오·장소·아이템·NPC·행동·이벤트·목표
  engine.js              규칙 "판정관": 생성·판정·NPC기억·이벤트·정산·목표
public/app.js            UI 컨트롤러(모바일형): 헤더·상태·피드·행동·탭·모달
```

## 확장 (DB 연결)

`public/store.js`의 `Store` 인터페이스(`save/load/clear/has`)만 Supabase 등으로 바꾸면 됩니다.
게임 상태는 단일 직렬화 가능한 객체이므로 그대로 행(row)으로 저장할 수 있습니다.

## 설정 (환경변수, 선택)

| 변수 | 기본값 | 설명 |
|------|--------|------|
| `OPENAI_API_KEY` | (없음) | UI에 키를 안 넣을 때 서버 프록시가 사용할 키 |
| `PORT` | `3000` | 서버 포트 |
